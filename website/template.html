02 / Architecture & Workflow

Engineered for shipping real UA creatives.

Not a throwaway HTML generator. Tora enforces structured scenes, automatic asset optimization, real provenance, and automated QA before export.

01

MCP-First ($0 API Cost) + Universal BYOK

Drive Tora from Claude Code, Cursor, Codex, or Gemini CLI using your existing coding subscription — or connect Gemini, OpenAI, Claude, OpenRouter, DeepSeek, Kimi, Qwen, GLM, or local Ollama/vLLM inside the visual Studio UI.

02

Atomic Editable 2D & 3D Scene Graph

Every playable lives in a strict structured scene schema validated across Node and Rust. Transforms, sprites, 3D meshes, physics, path networks, audio, events, and bindings update via revision-checked, undoable transactions.

03

Automatic Asset Optimization & Verified CC0

Drop studio PNG, JPEG, WAV, or MP3 files up to 8 MiB or fetch allowlisted CC0 Kenney/OpenGameArt packs. Tora keeps original masters, auto-optimizes delivery bytes under 700 KB, trims/slices sprites mechanically, and records SHA-256 receipts.

04

4-Viewport & Motion Filmstrip QA

Before export, Tora’s built-in Playwright QA runner tests portrait & landscape phone viewports, muted-until-tap audio unlock, text clipping, primary gameplay, and saves 8-frame motion filmstrips (plus optional WebM video).

03 / Tora vs. Using an LLM Directly

Why connect your LLM to Tora instead of prompting raw HTML?

Keep the AI coding agent you already use — Tora adds the structured engine, asset optimizer, QA, and 7-network packer.

Raw HTML Prompting

Using an LLM Directly

  • Rewrites full HTML files on small tweaks
  • Manual image & audio compression for ad size caps
  • Hand-rolled MRAID, DAPI & ZIP SDK wrappers
  • Desktop guesswork on safe areas & audio unlock
  • Code-only diffs with no visual review for teams
  • Burns tokens regenerating engine boilerplate
MCP · Open Source

Using Tora + Your LLM

  • Structured, editable scene graph with undo/redo
  • Auto asset optimization (8 MiB → ≤ 700 KB) + lossless restore
  • 7 verified HTML & ZIP ad-network exporters included free
  • Automated 4-viewport mobile & audio Creative QA
  • Visual Studio UI with frame notes & .tora.json handoff
  • Runs locally via MCP at $0 extra API cost
