# Contributing to Tora

Contributions are welcome! Whether you're fixing bugs, improving documentation, adding features, or supporting new ad networks, your help is appreciated.

## Getting Started

1. Fork and clone the repository.
2. Follow the setup instructions in the [README](README.md).
3. Create a branch for your changes.
4. Implement and test your changes.
5. Submit a pull request with a clear description.

For major changes, open an issue first.

## Guidelines

- Follow existing code conventions.
- Keep changes focused and maintainable.
- Include relevant tests and documentation.
- Preserve Tora's local-first, MCP-first architecture.
- Ensure you have the rights to any contributed code or assets.

AI-assisted contributions are welcome, provided they are reviewed and tested.
