# 3D pack

`native.stage3d.v1` defines the WebGL stage, lighting, camera, and optional follow target. `native.mesh3d.v1` declares bounded primitive or retained mesh geometry, transforms, color/texture use, lighting flags, and presentation options. Use the exact capability descriptors: some retained fields are specific to existing golf content.

`physics-3d` supplies bounded dynamic/static/kinematic movement. `aim-launch-3d` handles pullback or direct launch and trajectory display. `capture-zone-3d` performs speed/height-gated capture, and `oscillate-3d` moves a component sinusoidally. These are separate from 2D canvas physics and cannot be assumed interchangeable.

3D rendering uses the separately pinned trusted `native-3d` bundle and WebGL2. It is not a general rigged-skeletal, custom-shader, embedded-video, or unrestricted mesh pipeline. Keep geometry and effects bounded for mobile ad WebViews.

Verify actual WebGL output in every aspect ratio, including reduced motion, muted play, host suspend/resume, and fallback behavior. Inspect depth, silhouettes, camera framing, shadows, launch feedback, capture celebration, and Store CTA in packaged screenshots and footage. Static compilation does not establish rendering performance or device acceptance.
